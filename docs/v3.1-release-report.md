# V3.1 release-candidate report

Date: 2026-08-27. Baseline V3 commit: `f9db7dcece402167f36784f7336bc04405c4a6fc`.
The requested branch is a separate release candidate; `main`, `v1`, `v2`, and
`v3` are not merged or rewritten.

## Questions and answers

1. **V3 defects:** the baseline audit found policy-only marketplace guidance,
   a non-executing graph, thin routing cards, definition-only behavior cases,
   structural tests, incomplete CI/release automation, ambiguous templates,
   shallow anchors, no experiment/job runtime, and incomplete security
   enforcement.
2. **V3.1 fixes:** registries, resolver, delegation/handoff schemas, graph
   executor and immutable events, canonical templates, deep anchors, method /
   literature / experiment / job / review runtimes, behavior runner, CI,
   manifests, security cases, docs, and integration tests.
3. **Runtime router:** yes for local deterministic resolution through
   `scripts/skill_router.py inventory|resolve|team|validate-plan|explain`;
   external invocation remains host-owned.
4. **Capability registry:** capability IDs describe scientific work and risks;
   catalog entries are merely providers. The resolver chooses the smallest
   active qualified provider and records permissions/checker requirements.
5. **External skills:** exact pinned refs, license/scripts/dependencies/
   network/credentials/write scope and behavior status are audited. Only
   `SPECIALIST`/`PROVISIONAL` entries can be considered, and quarantine blocks
   execution; no skill is silently installed.
6. **Graph progression:** `plan-next`, `ready`, and `advance` materialize safe
   conditional readiness; `reopen`, `rollback`, `supersede`, `rebuild`, and
   `explain` provide recovery and inspection.
7. **History/projection:** `.research-graph-events.jsonl` is immutable event
   history with predecessor/event hashes; `research_graph.json` is a materialized
   projection that `rebuild` can derive and verify.
8. **Deep evidence:** local artifact existence, root containment, SHA256,
   line/row bounds, git commit resolution, command/exit status fields, and
   checker requirements are checked. External sources are `CONDITIONAL`.
9. **Literature:** discovery, identity, and claim-support verification are
   separate; stable identifiers and inspected regions are required, and
   snippets/metadata/abstract-only support is rejected or conditional.
10. **Experiment planning:** options are ranked by information gain, cost,
    risk, and reversibility; unlinked/outcome-independent work is dropped
    except explicit diagnostic, safety, reproducibility, or venue needs.
11. **Methods:** the machine-readable router returns definitions, estimands,
    assumptions, evidence, checks, escalation, and forbidden claims; high-risk
    tasks require a specialist or authoritative source record.
12. **Student autopilot:** orientation and feasibility are automatic within
    declared budget/permissions; scientific interpretation, ethics, major scope,
    high cost, irreversible actions, public release, and submission stop for the
    author.
13. **Profiles:** 13 domain cards and 16 study cards provide triggers,
    evidence expectations, failure modes, specialist escalation, and artifact
    expectations; they route decisions rather than pretend to be textbooks.
14. **Review runtime:** threat text activates only relevant attacks and roles;
    findings require anchors, uncertainty, smallest fix, verification, and
    residual risk. No reviewer vote or outcome forecast is used.
15. **Ambition analyzer:** levels A-E are reported across independent dimensions
    with `READY`, `PLAUSIBLE_WITH_GAPS`, or `NOT_YET_DEFENSIBLE`; no acceptance
    probability is computed.
16. **CI:** the committed workflow runs unit/integration tests, release and
    manifest checks on Ubuntu/Windows with Python 3.10/3.11/3.12; model eval is
    manual/optional. Local CI-equivalent checks pass; hosted GitHub Actions
    status is pending the branch upload.
17. **Test levels:** Level 1 deterministic/unit and schema checks pass; Level 2
    runtime integration checks pass (31 tests); Level 3 deterministic security
    pressure and hidden-answer harness pass, while external model trials are
    `NOT_RUN`; Level 4 synthetic end-to-end smoke passes.
18. **V3/V2 comparison:** the branch preserves V1/V2 and V3 refs. A same-model
    quantitative comparison is `NOT_RUN`; the harness explicitly avoids average
    scores and records case-level results only.
19. **Smoke run:** an isolated synthetic project completed 18 graph events,
    deep local anchor verification, pilot experiment planning, skill/method
    routing, literature query logging, and routing behavior evaluation.
20. **Qualified external skills:** PaperOrchestra and Sisyphus are
    `SPECIALIST`; the local native provider is `APPROVED` for its declared
    capabilities.
21. **Quarantined/provisional:** Academic Research Skills Codex and
    Open-Scholar are `QUARANTINED`; SNL writing, K-Dense, ARS, and Voidful are
    `PROVISIONAL` pending task trials. Other specialists remain conditional on
    live source access and permissions.
22. **Remaining MINOR defects:** no known critical/goal-blocking major defect;
    hosted CI observation, fuller schema keyword validation, and representative
    student usability trials remain minor release work.
23. **Unavoidable external risks:** host tool semantics, model behavior, live
    venue rules, paywalled source access, third-party repository changes, and
    network/API outages require re-verification at activation time.
24. **Merge decision:** do not merge automatically. The branch is suitable as a
    release candidate for author review; merge to `main` only after hosted CI,
    any desired model trials, and author review of the conditional external
    risks.
