evidence qualification. All six providers below execute selected, pinned
upstream resources locally. None is `QUALIFIED`, `EXTERNAL_BETTER`, or
`FORMAL_ELIGIBLE`.

## Reproducible execution

Run:

```text
python scripts/v41_provider_adapters.py audit
python scripts/v41_specialist_e2e.py --mode PUBLIC_CORE --output v41-public-core.json
python scripts/v41_specialist_e2e.py --mode PRIVATE_ULTRA --output v41-private-ultra.json
python -m unittest tests.test_v41_provider_integration tests.test_v41_provider_contracts -v
```

The E2E suite requires six executed providers, non-empty executed-resource
receipts, source/input/output hashes, and provider-specific semantic results.
It does not pass by inspecting registry entries or writing placeholder files.

candidates; SkillLens remains methodology-only; POPPER remains reference-only.
