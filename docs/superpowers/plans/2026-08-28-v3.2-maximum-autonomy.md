# V3.2 Maximum Autonomy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a fail-closed maximum-autonomy control plane, resumable director loop, completion contract, and deterministic full-paper E2E while preserving every v3.1.1 scientific and provenance contract.

**Architecture:** Add stdlib-only v3.2 modules around the existing v3.1.1 modules. `autonomy.py` owns policy, standing authorization, AUTO_HIRE decisions, and an independent hash-chained audit log. `director_loop.py` owns persistent sessions and bounded recovery while delegating graph mutations to `research_graph.py`. `completion_contract.py` and `full_paper_e2e.py` compose existing gates and evidence APIs without promoting legacy declarations.

**Tech Stack:** Python 3.10-3.12 standard library, JSON/JSONL state, `unittest`, existing repository scripts and public synthetic fixtures. No new third-party dependencies or skills.

## Global Constraints

- Baseline is `origin/main` SHA `6b34dcba551bdf200c2d7dd49bcb6b6057ef67c4`.
- Work only on branch `v3.2` in the sibling worktree `E:\学习\1\cs-nature-paper-skill-v3.2`.
- Preserve v3.1.1 provenance, evidence, research graph, scientific gates, security/privacy behavior, and all existing regression tests.
- Maximum autonomy is bounded and deny-by-default: no silent scientific decision, protocol mutation, private-data exposure, external write, publication, or submission.
- AUTO_HIRE requires exact immutable pin, license/source audit, passed behavior/security evidence, declared scope, and an authorization within the risk cap.
- Audit records are append-only canonical JSONL with predecessor and event hashes; tampering, reorder, truncation, and malformed records fail closed.
- Failed/partial artifacts are preserved or quarantined; self-healing may reopen/retry only within declared budgets and must never fabricate evidence.
- Deterministic E2E output is labeled `HARNESS_SELF_TEST`, not model behavior or scientific evidence.
- Every production behavior is covered by a test written and observed failing before implementation.

def test_audit_tamper_reorder_truncate_and_malformed_fail_closed():
    with tempfile.TemporaryDirectory() as tmp:

        autonomy.append_audit(original, "one", {}, actor="test", decision="AUTHORIZED", utc="2026-08-28T00:00:00Z")
        autonomy.append_audit(original, "two", {}, actor="test", decision="AUTHORIZED", utc="2026-08-28T00:00:01Z")
