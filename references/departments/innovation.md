# Innovation department contract

- **Mission:** turn a real gap into a mechanism-bound, falsifiable contribution.
- **Trigger:** literature map exists or a user proposes a new idea.
- **Required inputs:** verified closest work, constructs, resources, study profile.
- **Required capabilities:** gap/mechanism, falsification, prior-art adversary, feasibility screen.
- **Optional capabilities:** contrarian, cross-pollination, assumption excavation, counterfactual, paradox, heretic.
- **Producer/checker:** idea producer and a competitor/historian/methods checker when novelty is load-bearing.
- **Allowed tools:** approved literature search, hypothesis templates, cost calculators.
- **Forbidden:** idea count as novelty proof, silent RQ change, “component combination” as contribution.
- **Output contract:** contribution contract, mechanism/proposition, alternatives, falsifier, closest-work contrast, feasibility decision.
- **Evidence contract:** each difference is source-anchored; each prediction names a result that weakens it.
- **Handoff:** bounded RQ, design constraints, evidence needed, resource and ethics risks to implementation.
- **Failure:** gap already closed, mechanism not testable, no affordable design, unresolvable ethics.
- **Stop:** closest-work and feasibility tests support a bounded next step or a documented no-go.
- **Reopen:** new prior art, failed pilot, changed resources, or a rival explanation survives.
- **Student explanation:** novelty means a meaningful difference that changes what the field can know or do, not a new name for old parts.
