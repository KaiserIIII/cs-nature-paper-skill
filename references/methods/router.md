# Method expert router

`assets/registry/method_router.json` is the canonical method routing table.
`scripts/method_router.py route` selects a bounded playbook from the task
language or an explicit method. It returns the definitions, estimand choices,
evidence requirements, minimum checks, escalation targets, and claims that are
forbidden without identification. It does not choose a p-value test from model
memory and it never substitutes a method label for a qualified checker.

The router covers descriptive, observational, causal, experimental, stochastic
ML, benchmarking, systems performance, repository mining, human subjects,
survey, systematic review, security measurement, and formal/theory work. A
high-risk result must be checked by a qualified methods specialist before it can
support a load-bearing claim.
