# Context and token budget

Load the entrypoint first, then one core file, one department file, one domain
profile, and one study profile. Add methods or venue references only when the
next graph node requires them. Summarize completed handoffs by artifact path,
hash, decision, uncertainty, and next owner; do not replay whole transcripts.

Prefer deterministic scripts for schemas, hashes, graph transitions, migration,
and linting. Parallelize independent literature, innovation, or review roles
only when the host supports them and the employee contract records the cost.
Stop or checkpoint when the declared budget is exhausted; more agents or tokens
are not evidence.
