# Domain profile: software engineering

- Contributions: tool, process, empirical finding, repository mining, developer support, or benchmark.
- RQs/evidence: developer outcome, repository phenomenon, tool effect, maintenance or quality construct with unit and sampling frame.
- Baselines: current tool/process and simple heuristic; match repository/project maturity and human effort.
- Threats: selection and survivorship bias, construct proxy, confounding, leakage across repositories, observer and intervention effects.
- Experiments/statistics: study-type profile decides design; report coverage, denominators, clustering, missingness and effect uncertainty.
- Artifacts/reviewer focus: repository snapshot/license, mining queries, annotation protocol, tool version, privacy and ethics.
- Fatal mistakes: population claims from convenient repositories, equating static metrics with quality, deleting failures.
- Specialists: empirical methods, causal/statistical analysis, artifact and human-study ethics.
