# Domain profile: programming languages

- Contributions: language feature, type/effect system, compiler, verification method, or empirical language study.
- RQs/evidence: soundness/completeness, performance, expressiveness, developer outcome, or bug/failure behavior with formal scope.
- Baselines: established language/compiler/tool and closest mechanism; disclose benchmark and timeout policy.
- Threats: unsound assumptions, benchmark overfitting, unreported timeouts, oracle bias, unsupported language subset.
- Experiments/statistics: proof obligations or benchmark distributions as appropriate; human study only with its own design profile.
- Artifacts/reviewer focus: formal definitions/proofs, compiler revision, suite/license, scripts, counterexamples, environment.
- Fatal mistakes: confusing type-checking with correctness, hiding failed proofs/cases, generalizing from one language subset.
- Specialists: theory, compiler engineering, formal verification, empirical methods.
