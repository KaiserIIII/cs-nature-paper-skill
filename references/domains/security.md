# Domain profile: security

- Contributions: threat model, defense, vulnerability measurement, protocol, or usable security evidence.
- RQs/evidence: attack success, false positives, cost, coverage, exploitability, or user harm under explicit threat boundaries.
- Baselines: deployed/common defense and strongest comparable attack/defense; define attacker capabilities.
- Threats: unrealistic attacker, incomplete disclosure, benchmark leakage, unsafe experiments, dual-use and privacy risk.
- Experiments/statistics: red-team/failure cases, confidence bounds and responsible handling; no live targets without authorization.
- Artifacts/reviewer focus: threat model, sandbox, disclosure plan, data/credential controls, reproducible safe fixtures.
- Fatal mistakes: testing third-party systems without permission, publishing exploit details irresponsibly, claiming security from a toy attack.
- Specialists: security review, ethics, privacy, formal methods, artifact sandboxing.
