# Domain profile: empirical software engineering

- Contributions: repository mining finding, developer study, tool evaluation, process intervention, or replication.
- RQs/evidence: project/developer behavior, defect/process outcome, intervention effect, or measurement validity with a sampling frame.
- Baselines: prior operationalization and current tool/process; align repositories, time windows, effort and confounders.
- Threats: repository selection, survivorship, construct validity, temporal leakage, clustering, researcher degrees of freedom, privacy.
- Experiments/statistics: define unit, denominator, dependence, missingness and estimand; use causal or observational profile as appropriate.
- Artifacts/reviewer focus: immutable snapshots, queries, licenses, coding guide, analysis scripts, data release boundary.
- Fatal mistakes: treating GitHub as a random population, equating commits with productivity, hiding excluded repositories.
- Specialists: causal/statistical methods, repository mining, human/ethics and artifact evaluation.
