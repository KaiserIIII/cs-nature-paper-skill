# Domain profile: natural language processing

- Contributions: model, representation, corpus, annotation, evaluation, or linguistic analysis.
- RQs/evidence: task performance, linguistic phenomenon, fairness, transfer, or data effect with a defined population and metric.
- Baselines: simple lexical/classical, competitive pretrained, and closest mechanism baseline.
- Threats: contamination, annotation disagreement, template artifacts, demographic imbalance, tokenizer effects, spurious correlations.
- Experiments/statistics: paired bootstrap or appropriate uncertainty, slice/error analysis, ablation only for mechanism claims.
- Artifacts/reviewer focus: corpus provenance/license, preprocessing, prompts, annotator protocol, code and evaluation scripts.
- Fatal mistakes: unverified human labels, aggregate scores without slices, calling correlation a linguistic cause.
- Specialists: NLP evaluation, human study, privacy and language-specific review.
