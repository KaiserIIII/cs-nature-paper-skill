# Domain profile: human-computer interaction

- Contributions: interaction technique, design theory, user behavior, accessibility, or deployment insight.
- RQs/evidence: task performance, experience, behavior, adoption, or mechanism with participant/sample and context boundaries.
- Baselines: established interaction or user workflow with matched training, order, and task burden.
- Threats: demand characteristics, learning/order effects, sample bias, instrument validity, privacy, accessibility and researcher influence.
- Experiments/statistics: study-type profile controls power/analysis; report uncertainty, exclusions, qualitative coding and inter-rater process.
- Artifacts/reviewer focus: preregistration/ethics, consent, anonymization, materials, scripts, accessibility and analysis code.
- Fatal mistakes: coercive or unapproved studies, post-hoc coding without audit, generalizing convenience users to all users.
- Specialists: human-study statistics, qualitative methods, accessibility, ethics.
