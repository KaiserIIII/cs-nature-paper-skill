# Domain profile: computer vision

- Contributions: representation, detector/segmenter, data/augmentation, robustness, or visual measurement.
- RQs/evidence: task metric, calibration, spatial/semantic failure pattern, or deployment constraint with dataset and label scope.
- Baselines: standard architecture and current strong method under matched preprocessing and compute.
- Threats: train/test leakage, annotation noise, class imbalance, shortcut features, resolution/camera shift, metric masking.
- Experiments/statistics: per-class and subgroup results, robustness or OOD only for relevant claims; preserve raw predictions.
- Artifacts/reviewer focus: dataset/license, preprocessing, seeds, checkpoints, visualization of errors, vector plots and source masks.
- Fatal mistakes: qualitative examples selected after seeing results, hidden cropping, reporting only aggregate accuracy.
- Specialists: imaging, accessibility, statistical uncertainty, dataset governance.
