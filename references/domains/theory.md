# Domain profile: theory

- Contributions: theorem, lower/upper bound, algorithm, model, or formal characterization.
- RQs/evidence: definitions, assumptions, proof or counterexample, complexity, and relation to prior bounds.
- Baselines: closest formal model and strongest known bound; compare assumptions before numerical results.
- Threats: hidden assumptions, quantifier errors, invalid reductions, incomparable models, unproved implementation claims.
- Experiments/statistics: optional sanity checks or empirical illustration; they cannot replace a proof obligation.
- Artifacts/reviewer focus: complete definitions, proof sketches/full proof, machine-checkable artifact when feasible, examples/counterexamples.
- Fatal mistakes: presenting conjecture as theorem, using simulations as proof, changing model in a comparison.
- Specialists: formal reviewer, theorem prover, algorithm specialist.
