# Domain profile: large language models

- Contributions: prompting, training, alignment, agent/tool use, evaluation, safety, or systems around LLMs.
- RQs/evidence: task success plus cost, latency, calibration, robustness, or failure mechanism; define prompts and model snapshots.
- Baselines: relevant closed/open models, strong prompting, retrieval/tool ablations, and budget-matched alternatives.
- Threats: benchmark contamination, prompt leakage, evaluator bias, stochastic decoding, API drift, hidden system prompts, cherry-picking.
- Experiments/statistics: fixed prompt/seed/model versions, paired cases, human or judge agreement when needed, uncertainty and error taxonomy.
- Artifacts/reviewer focus: prompts, model IDs, API terms, costs, rate limits, privacy, refusal/failure examples, replayable logs.
- Fatal mistakes: treating judge scores as ground truth, exposing private inputs, claiming reasoning from text alone, ignoring model updates.
- Specialists: LLM evaluation, privacy/security, cost instrumentation, human-study methods.
