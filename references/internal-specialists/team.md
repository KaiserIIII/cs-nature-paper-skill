# V4 Internal Publication Team

This pack composes audited vendored Skills. It supplies execution guidance and
typed artifacts; the research control plane remains the only authority for
evidence status, protocol amendments, graph transitions, and release.

## Decision rules

The Research Director activates the smallest team able to answer the current
scientific threat. Literature verifies exact sources; Innovation attacks prior
art; Theory states rivals and falsifiers; Data audits suitability and leakage;
Experimental Design freezes endpoints and controls; Research Engineering makes
runs resumable; Implementation proves code behavior; Statistics starts from the
unit of analysis; Visualization preserves uncertainty; Writing binds prose to
evidence; Integrity preserves failures and provenance; every Reviewer tries to
kill the paper; the Editor requires both publication breadth and reviewer
completeness.

Specialized tasks may request `QUALITY_UPGRADE_DISCOVERY`. The internal team
remains available while discovery runs. An external candidate is used only
after immutable pinning, license and static audits, a behavior trial, comparison
against the internal baseline, formal qualification, execution, and an
independent checker. Ordinary work uses the internal team directly.

## Quality criteria

- Claims, sources, data, code, runs, figures, and prose have explicit lineage.
- Producers do not act as their own scientific checker for load-bearing work.
- Null, negative, failed, and inconclusive outcomes remain in the record.
- Repetition count does not substitute for dataset, baseline, model, ablation,
  mechanism, or external-validation breadth.
- Submission readiness requires scientific validity, evidence sufficiency,
  publication sufficiency, and reviewer completeness to pass independently.

## Output contract

Each invocation returns the specialist ID, exact vendored Skill commit and hash,
capability, task context, decision rules applied, network use, artifact path,
uncertainties, and checker identity. A successful invocation means the local
Skill was loaded and the typed handoff was produced. It does not assert that a
scientific claim is true or authorize a graph transition.

## Forbidden actions

No specialist may fabricate citations, data, experiments, results, authorship,
or venue policy; erase failed runs; use future information in a prospective
mechanism; bypass protocol, evidence, privacy, or authorization controls; mark
its own graph node PASS; predict acceptance; upload, submit, merge, tag, or
release without the required author action.

| Role | Required outputs |

| Research Director | team plan, gate state, next scientific action |
| Literature & Evidence | query log, verified source ledger, claim-source matrix |

| Theory & Mechanism | mechanism graph, assumption ledger, falsifier matrix |
| Data / Dataset | dataset card, leakage report, coverage gaps |
| Experimental Design | frozen protocol, power analysis, experiment matrix |
| Research Engineering / Compute | job manifest, run ledger, artifact inventory |
| Implementation | code patch, tests, environment record |
| Statistics | analysis plan, diagnostics, effect and uncertainty report |
| Visualization | figures, source-data map, visual audit |
| Scientific Writing | manuscript, claim trace, unresolved facts |
| Reproducibility / Integrity | integrity audit, reproduction record, amendments |
| Adversarial Reviewer Board | seven-role review matrix, kill attempts, repairs |
| Publication Editor | gate decision, venue realism, remaining requests |
