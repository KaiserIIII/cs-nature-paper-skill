# Student-first mentoring contract

For each unfamiliar decision, give only the knowledge needed now:

```text
Concept: what it means in plain language
Why it matters: which claim or decision it protects
Example: one concrete research example
What can go wrong: the likely failure if ignored
Recommended decision: the CEO default and why
Author choice: only when evidence or authority cannot decide
```

Example: a baseline is an existing method used for a fair comparison. Without
strong, comparable baselines, an improvement may only reflect tuning or setup.
The CEO should identify a classical, current strong, and mechanism-near
baseline, check licenses and comparable inputs, then recommend the smallest set
that can distinguish the proposed mechanism. Do not ask the student to select
from unexplained names.
